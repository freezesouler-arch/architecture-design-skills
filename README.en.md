# Architecture Design Skills

Three practical agent skills for architectural visualization, design development, and district concept planning. [中文](README.md)

| Skill | Purpose |
|---|---|
| [architectural-white-model](skills/architectural-white-model/SKILL.md) | Refine model views into white-clay visualizations while checking camera, geometry, landscape, and water boundaries. |
| [architectural-design-workflow](skills/architectural-design-workflow/SKILL.md) | Organize briefs, benchmark evidence, design alternatives, authoritative models, review issues, and presentation narratives. |
| [district-concept-planning](skills/district-concept-planning/SKILL.md) | Connect district development with public value, industry, talent needs, measurable commitments, and implementation responsibility. |

## Install

Clone or download this repository. Copy the desired complete folders from `skills/` into your agent's configured skills directory. Preserve all references. For Codex, use the configured `$CODEX_HOME/skills` directory, normally `~/.codex/skills` when not customized. Back up any existing skills with the same names. Other agents must support SKILL.md loading; cross-agent compatibility has not been comprehensively tested.

## Use

Ask your agent to use the skill by name, supply your project inputs, and specify the desired stage and outputs. Instructions are primarily in Chinese. See [example requests and acceptance criteria](examples/README.md).

These are instructions, not standalone modeling or rendering software. Image editing requires a reference-image-capable tool; current policy and case research require source access; geometry analysis requires appropriate models and software. No API keys, paid services, private project assets, or client data are included.

Examples are fictional teaching scenarios, not completed projects or generated render benchmarks. Outputs support professional judgment and do not replace statutory review or engineering verification.
