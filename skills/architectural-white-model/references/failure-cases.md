# 白模表达常见错误与检查方法

以下为跨项目可复用的错误类型；每次仍以本项目底图为唯一几何依据。

## 典型错误与检查方式

| 情况 | 错误 | 处理 |
|---|---|---|
| 对岸背景地块 | 生图把连续陆地改成大水面，对岸建筑落在狭窄孤岛 | 原截图划清陆水归属，仅改错误水域，锁定主河岸 |
| 多方案相似鸟瞰 | 上一案低层叠墅替换新案的高低组合住宅 | 各自底图独立，风格参考禁止提供布局；逐栋对照屋顶和高度 |
| 植物贴图 | 立面树片被误判为多余实体墙 | 从模型或原图辨认，细化为树冠，不新增片墙 |
| 圆形构筑物 | 环形亭生成实心圆盘 | 锁定环形屋顶和中庭开口 |
| 水庭前景竖面 | 竖向池壁误生成瀑布 | 以实体白色池壁表达，区分水平水面和竖面 |
| 入口车辆 | 原有落客车移进玻璃大堂 | 保持室外车辆位置和人行通道 |
| 以效果代校核 | 提示词写了“4米/13层”就称已核对 | 层高与净高分开；模型重读才是尺寸证据，截图仅视觉核对 |
