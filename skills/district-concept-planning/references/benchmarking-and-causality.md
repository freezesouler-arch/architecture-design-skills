# 案例对标与因果分析

## 选例矩阵

每个案例先回答“它证明什么”。优先用4–6个互补案例，不以数量取胜。

| 证明任务 | 适合案例 |
|---|---|
| 龙头改变区域 | 企业开放研发资源、人才和供应链形成生态 |
| 调规形成公共价值 | 城市以规划弹性换住房、公园、交通和长期协议 |
| 科研转化为产业 | 大学、实验室、资本、孵化和城市生活高密度组合 |
| 企业周期后的韧性 | 校友、人才外溢、连续创业和再投资体系 |
| 城市形象更新 | 片区更新成为公共目的地、文化名片和全球传播载体 |

## 单案例分析模板

1. **起点**：更新前的经济、空间和治理问题；
2. **关键主体**：政府、企业、大学、开发商、社区和运营方各自角色；
3. **政策工具**：规划、协议、土地、税费、基础设施或监管确定性；
4. **空间工具**：功能复合、共享设施、公共空间、交通和生态；
5. **运营工具**：平台招商、孵化、活动、资本、社区和品牌；
6. **因果链**：为什么这些动作导致所宣称的结果；
7. **结果证据**：公司、人才、就业、投资、住房、客流、开放空间或城市品牌；
8. **限制条件**：时间、政府投入、机构能力、市场与文化差异；
9. **项目转译**：可复制机制、不可复制形象、必要前置条件。

## 一页案例的表达

当案例需要压缩为一页，使用四段式：

`原问题` → `政策/规划动作` → `产业与空间机制` → `城市结果及本项目启示`

图片服务于因果链：区域鸟瞰说明尺度，总图说明规划工具，街景说明公共生活，运营照片说明真实使用。不要用四张相似效果图代替分析。

## 多页案例的表达

3–5页案例建议：

1. 起点问题与城市背景；
2. 关键政策、规划和主体行动；
3. 因果机制图；
4. 空间及运营场景；
5. 结果、限制与项目转译。

## 证据等级

- A：政府、法定规划、开发协议、机构年报、官方统计；
- B：项目官网、设计机构、大学或运营方；
- C：专业媒体与研究论文；
- D：新闻转述、营销文章和社交媒体，仅作线索。

数字尽量使用A/B级证据。形象图可来自设计机构或项目方，但不得据此推断运营成效。

## 转译句式

用机制表述：“案例通过X政策和Y平台，使Z主体形成高频连接，进而产生N结果；本项目可转译的是Y与治理关系，而非其建筑形象。”

避免：“借鉴其开放街区、绿色屋顶和丰富业态。”这种句子缺少主体、政策、因果和结果。
