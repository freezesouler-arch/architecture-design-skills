# 指标、治理与政府问答

## 指标体系

可按项目调整为六大类：

1. 产业创新：产业容量、共享研发、孵化、企业服务、成果转化；
2. 生活宜居：住房结构、托育、健康、体育、社区服务；
3. 文化交往：文化空间、餐饮零售、咖啡茶饮、活动与国际交流；
4. 智慧交通：轨道接驳、步行骑行、无障碍、低碳出行和数字交通；
5. 生态韧性：开放空间、绿地连续、遮阴雨棚、海绵、能耗与生物多样性；
6. 运营治理：责任主体、开放时段、活动频率、维护、数据与年度评估。

每项指标使用以下字段：

| 字段 | 要求 |
|---|---|
| 指标名称 | 能直接理解，不混合多个概念 |
| 类型 | 容量 / 可达 / 品质 / 运营 / 治理 |
| 现状值 | 范围、时间与来源明确 |
| 参考值 | 法定标准或案例区间，注明性质 |
| 片区缺口 | 计算关系明确 |
| 项目承担 | 数量、面积、比例或绩效 |
| 空间落位 | 地块、楼层或公共空间 |
| 实施阶段 | 规划、方案、建设、招商、运营 |
| 核验口径 | 图纸、测绘、台账、客流或第三方评估 |
| 责任主体 | 政府、开发商、物业、运营方或合作机构 |

咖啡馆、图书馆等生活设施优先以服务人口、步行覆盖和经营面积交叉校核；“每平方公里数量”仅作为案例比较，不直接等同项目义务。

## 公共价值兑现工具

- 规划条件：适合刚性面积、比例、连通和开放要求；
- 开发协议：适合分期、基础设施、住房、资金和多主体责任；
- 方案审查：适合公共空间骨架、界面、视廊和交通；
- 建设验收：适合面积、设备、无障碍与实体完成度；
- 招商/运营协议：适合业态、服务平台、开放时间和活动；
- 年度评估：适合客流、孵化、活动、能源与维护表现。

不要把不可由项目单方控制的结果写成硬承诺，例如“孵化一家独角兽”。可承诺的是形成条件和过程指标，例如共享实验空间、服务企业数量、创业活动、资本对接和孵化项目数。

## 政府可能关心的问题

### 产业是否被削弱？

用片区产业容量、项目保留容量和需求测算回答；说明新增功能如何提高人才稳定、研发效率和产业外溢。不能只用“产城融合”口号。

### 为什么必须调整用地？

比较不调整与调整情景，证明结构性缺口无法仅靠原用途解决；同时说明调整边界和附加公共责任。

### 是否变相房地产化？

说明产业底盘、使用边界、住房对象/产品逻辑、公共服务、运营平台和长期监管；提出可核验条款。

### 城市具体得到什么？

列出新增公共空间、服务、住房、产业平台、交通生态改善、投资就业与城市品牌，并区分直接结果和长期愿景。

### 谁来建设和运营？

列责任主体、资金来源、分期节点、开放要求、维护机制、KPI和退出/替代机制。

### 案例为什么适用于这里？

说明转译的是政策、平台、邻近关系或运营机制；同时列出规模、制度、市场和文化差异，不复制形象。

## 最终QA表

逐页检查：

- 标题与页面证据是否一致；
- 数据和图是否使用同一范围；
- “项目建议规模”与“项目补足量”是否解释差异；
- 同一功能名称、目标名称和导则标题是否全篇统一；
- 案例结论是否在指标和方案页落地；
- 规划条件、建议值、案例值和愿景值是否明确区分；
- 是否存在替政府决策、承诺审批或夸大城市影响的绝对表述。
