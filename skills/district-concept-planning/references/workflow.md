# 片区概念方案工作流

## 1. 定义本轮决策

先写一句“这轮需要谁决定什么”。常见决策包括：是否继续深化、是否接受功能调整方向、是否启动政府沟通、是否锁定规划条件、是否进入城市设计。

同步建立决策者关切：

| 对象 | 首要关切 | 需要的证据 |
|---|---|---|
| 开发商高层 | 方向是否成立、资产是否可实施、政府为何支持、风险能否控制 | 情景测算、权益—责任交换、案例、分期与退出路径 |
| 政府/规划部门 | 产业是否受损、公共利益是否增加、承诺能否兑现、是否可复制 | 产业容量、职住供需、公共服务缺口、政策工具、责任与核验 |
| 设计评审 | 目标如何成为空间、技术是否成立、方案是否一致 | 总图、剖面、指标、交通生态分析、场景与导则 |

## 2. 建立事实底板

形成一张可追溯底表：地块、权属、现状及规划用途、容积率、计容面积、已出让/未出让、产业容量、人口与岗位、周边1公里和15分钟设施、交通、生态与实施状态。

关键数字记录：`值 + 单位 + 空间范围 + 时间 + 来源 + 适用阶段`。

## 3. 做反事实与情景对照

至少比较：

- A 保持现状：产业供给、开发难度、人才生活、公共服务、城市形象；
- B 调整后：保留的底盘、新增功能、公共价值、市场与治理风险；
- C 可选折中：调整强度、分期、附带条件。

反事实的作用是证明“为什么现在需要改变”，而不是证明开发商一定正确。

## 4. 提炼结构性矛盾

把具体问题归入3–5个城市级矛盾，例如：

- 产业容量充足，但人才生活和交流载体不足；
- 就业高度集聚，但住房与公共服务没有同步；
- 有研发楼宇，但缺少共享设施、孵化和资本网络；
- 有绿地指标，但公共空间不连续、不可达或不可运营；
- 有开发建设，但缺少分期责任与长期运营主体。

每个矛盾必须有数据、空间图或案例证据。

## 5. 做案例因果研究

选择能分别回答不同问题的案例，而不是重复同一类型：

- 龙头企业如何开放资源；
- 功能调整如何换取城市公共价值；
- 大学/科研如何完成商业化；
- 企业周期后如何保留人才与创业网络；
- 更新项目如何改善全球城市形象与公共生活。

## 6. 建立价值主张

将案例机制与场地矛盾交叉，形成3–5个项目目标。每项目标填写：

| 字段 | 内容 |
|---|---|
| 城市问题 | 当前缺口及影响 |
| 目标 | 想形成的城市能力 |
| 项目作用 | 本项目承担什么，不承担什么 |
| 空间响应 | 功能、公共空间、交通、生态、体量 |
| 运营响应 | 招商、服务、活动、维护与治理 |
| 指标 | 数量、可达、品质、绩效 |
| 风险 | 最大不确定性与验证动作 |

## 7. 构造公共价值交换

采用双栏台账：

| 项目需要的弹性 | 城市获得的增量 |
|---|---|
| 用地功能调整 | 职住平衡、人才住房或生活服务 |
| 容量/分期弹性 | 公共空间、基础设施同步实施 |
| 产品类型弹性 | 明确使用边界、运营责任与年度核验 |
| 开发强度优化 | 产业平台、文化设施、生态或交通贡献 |

每项城市增量必须对应交付节点、责任主体和核验材料。

## 8. 推导概念方案

空间推导顺序优先为：

1. 不可变约束与必须保留的价值；
2. 公共空间、生态和慢行骨架；
3. 功能与全天候活动分布；
4. 产业、居住和公共服务之间的邻接关系；
5. 体量、天际线、视廊与城市界面；
6. 关键场景和运营脚本；
7. 技术指标、分期和责任。

先定公共价值骨架，再校准可开发体量。

## 9. 压缩与复核

删并页遵循：同一结论只保留最强证据；趋势与案例不重复；目标与方法不重复；案例启示若不能落到后文则删除；设计页若不能证明前文目标则重写标题或调整图。

最终输出一张闭环矩阵：`问题—案例—目标—原则—动作—指标—责任—页码`。
